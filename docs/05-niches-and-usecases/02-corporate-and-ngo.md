# 02. Corporate & NGO Layouts

**File:** `docs/05-niches-and-usecases/02-corporate-and-ngo.md`  
**Module:** Niches & Usecases  

## 1. Corporate Strategy
Corporate sites demand high trust, performance, and SEO/GEO dominance.
* **Answer-First Patterns:** Hero sections and Service pages must implement the "Answer-First" philosophy, placing concrete metrics and summaries at the top of the viewport for AI agents.
* **Synced Pattern Overrides:** Testimonial grids, pricing tables, and team profiles utilize Synced Pattern Overrides. This locks the structural design globally while allowing content editors to change the text and images locally.

## 2. NGO / Non-Profit Strategy
The NGO niche shares structural DNA with the corporate layout but shifts focus toward emotional engagement and conversions.
* **Impact Metrics Grid:** Native grid blocks displaying real-time statistics, optimized with proper ARIA labels.
* **Donation Forms:** Integrated seamlessly using the Interactivity API to ensure fast, zero-refresh modal popups for single-click giving workflows.
