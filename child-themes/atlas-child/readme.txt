Official Zero-PHP Child Theme boilerplate and starter for the Atlas Multipurpose Parent Theme.

== Description ==

Atlas Child Starter is a minimal, ultra-clean Full-Site Editing (FSE) child theme designed as a blank foundation for bespoke projects, custom client websites, and developer experiments.

Key Architectural Highlights:
* 0 KB PHP footprint: No functions.php file.
* Cascading design tokens via theme.json v3.
* Pure HTML templates and template parts.
* Inherits native Interactivity API stores, accessible patterns, and CSP headers from atlas-theme.

== Installation ==

1. Ensure Atlas Multipurpose (atlas-theme) is installed in wp-content/themes/atlas-theme.
2. Upload and install atlas-child in wp-content/themes/atlas-child.
3. In WordPress Admin, navigate to Appearance > Themes and activate Atlas Child Starter.
