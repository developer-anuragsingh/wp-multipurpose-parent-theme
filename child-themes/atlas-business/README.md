# Atlas Business (Turnkey Corporate Child Theme)

A modern, high-performance, **turnkey Zero-PHP Child Theme** for the [Atlas Multipurpose Parent Theme](https://github.com/developer-anuragsingh/wp-multipurpose-parent-theme).

> **Role:** Production-ready niche theme for enterprise, consulting, SaaS, and B2B digital experiences. For a blank starter boilerplate, see `child-themes/atlas-child`.

Designed specifically for modern B2B enterprises, corporate organizations, consulting firms, and agencies requiring authority, modern aesthetics, and verified performance.

## Key Architectural Principles
- **0 KB PHP:** Strict Zero-PHP architecture. No `functions.php`. Fully leverages WordPress Full-Site Editing (FSE) cascading.
- **Design Tokens First:** Executive color palette (`#0f172a`, `#2563eb`, `#059669`), modern ambient shadows, and fluid typography cascading through `theme.json`.
- **Inherited Security & Speed:** 100% of the parent theme's Content Security Policy (CSP), timed-token CSRF/bot mitigation, and 100/100 Core Web Vitals are preserved.

## Included Templates & Parts
- `templates/front-page.html`: Modern high-impact enterprise showcase with Hero, Capabilities, ROI Metrics, and Executive CTA.
- `parts/header.html`: Modern executive navigation bar with direct Consultation CTA.
- `parts/footer.html`: Clean 4-column corporate footer with system status and SLA badge.

## Installation & Activation
1. Ensure the parent theme (`atlas-theme`) is installed in `wp-content/themes/atlas-theme`.
2. Copy or symlink this folder to `wp-content/themes/atlas-business`.
3. In WordPress Admin, navigate to **Appearance → Themes** and activate **Atlas Business**.
