Modern, turnkey Zero-PHP Child Theme built for enterprise, B2B, consulting, and corporate digital experiences on top of Atlas Multipurpose.

== Description ==

Atlas Business provides a polished corporate aesthetic with high-contrast executive palettes, tailored typography, high-impact services bento grid, and specialized templates ready for immediate production deployment.

Key Architectural Highlights:
* 0 KB PHP footprint: 100% Zero-PHP Full-Site Editing child theme.
* Enterprise design tokens with Deep Navy (#0b132b) and Emerald Accent (#10b981).
* Tailored bento grid patterns and conversion-optimized front-page layout.
* Full compatibility with core Speculation Rules, SEO schemas, and bank-grade CSP nonces.

== Installation ==

1. Ensure Atlas Multipurpose (atlas-theme) is installed in wp-content/themes/atlas-theme.
2. Upload and install atlas-business in wp-content/themes/atlas-business.
3. In WordPress Admin, navigate to Appearance > Themes and activate Atlas Business.
